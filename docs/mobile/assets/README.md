# Icônes mobiles

Générées depuis `public/icon.svg` par `node scripts/generate-mobile-icons.mjs`. PNG opaques : Apple 1024 × 1024 et Google Play 512 × 512. Les captures d’écran doivent provenir des applications natives réellement exécutées ; aucune capture promotionnelle fictive n’est fournie. Le nom et la marque restent à confirmer avant publication.
